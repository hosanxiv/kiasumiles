Connect KiasuMiles

KiasuMiles ONLY works with AI assistants that can use external tools. Choose yours for the right setup.

Paste this into an AI agent that can add remote MCP connections.

Set up once on ChatGPT web, then use KiasuMiles in Work on web or mobile. Tested on a ChatGPT Pro account; availability may vary.

  1. On ChatGPT web, go to Settings → Plugins → Developer mode and enable it.
  2. Open Plugins from the sidebar. Click the + beside the search bar to open New Plugin.
  3. Enter KiasuMiles as the name, choose Server URL, and enter https://kiasumiles.space/mcp. Set Authentication to No Auth. Leave the optional fields blank.
  4. Read the warning, tick I understand and want to continue, then select Create → Connect.
  5. Start a Work conversation on web or mobile and paste the prompt below. Approve Connect again if asked.

Set up once in the Claude app, then use KiasuMiles in a conversation with the connector enabled. Tested in Claude chat and Cowork on desktop; mobile availability may vary.

  1. In the Claude app, go to Settings → Customise → Connectors → Add custom connector.
  2. Enter KiasuMiles as the name and https://kiasumiles.space/mcp as the server URL.
  3. Select Continue and complete the connection prompts.
  4. Start a new conversation, enable KiasuMiles from the + menu, and paste the prompt below.

Questions I get about KiasuMiles.

What is KiasuMiles?

I built KiasuMiles so your AI agent can pick the best card from the ones you own. It matches the merchant and payment method against Singapore credit-card miles rules, then returns the conditions and a fallback.

Will it work with my AI assistant?

KiasuMiles ONLY works with AI assistants that can use external tools. Use the setup tab for AI agents, ChatGPT Work or Claude above. Some agents can handle the connection with your approval; ChatGPT Work and Claude need a one-time setup in their settings.

Can I use it on my phone?

We tested ChatGPT Work on mobile after setting up KiasuMiles once on ChatGPT web, using the same Pro account. You can then ask Work which card to use. Availability may vary by account and plan; this test does not cover ordinary ChatGPT Chat.

Do I need to wait for a public plugin?

No. The custom connection described above worked in ChatGPT Work without public directory approval. Complete that one-time setup first, then use the prompt. If the assistant cannot access KiasuMiles, it should tell you rather than guess.

Does KiasuMiles store my cards?

For each lookup, your agent sends the card names you confirmed. The hosted service returns an answer without keeping a wallet. We never receive your card number, expiry date, or CVV.

How accurate are the recommendations?

I keep the card rules and merchant matches updated, but banks change their terms and merchants sometimes process payments under an unexpected category. Check the conditions and fallback before you tap.

What if a merchant or card rule looks wrong?

Send me feedback through Telegram with the merchant name, outlet, and how you paid. Leave out your card number and any personal payment details.
