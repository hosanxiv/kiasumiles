Privacy Policy

Last updated: 13 July 2026

KiasuMiles provides Singapore credit-card miles recommendations through a hosted MCP service.

Your card stack

The agent or local client supplies selected card products for each lookup. Hosted KiasuMiles uses them only to calculate the requested recommendation and does not store the stack.

Request data

A lookup may include a merchant name, outlet, payment channel, category, and the selected card products. The service uses that information to calculate and return the lookup result.

Operational logs

Operational logs help maintain reliability and investigate errors. We aim to avoid logging sensitive personal information or complete request payloads.
